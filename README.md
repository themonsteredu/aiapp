# AI 온라인 플랫폼 관리자 — 진로교육 PPT 웹앱

PPT를 **웹앱 슬라이드**로 만들어 관리·발표하고, **요일·시간 기반으로 학생 접근을 통제**하며, **복제·캡처를 억제**하는 진로교육용 플랫폼입니다.

외부 패키지 없이 Node.js 내장 모듈만 사용하므로 설치 과정이 없습니다.

## 실행 방법

```bash
# Node.js 22.13 이상 필요
npm start        # 또는: node --no-warnings server.js
```

브라우저에서 `http://localhost:3000` 접속.

- 포트 변경: `PORT=8080 npm start`
- 데이터 저장 위치: `./data/app.db` (SQLite, 자동 생성) — `DATA_DIR` 환경변수로 변경 가능
- 기준 시간대: `Asia/Seoul` — `APP_TIMEZONE` 환경변수로 변경 가능

### 최초 로그인

첫 실행 시 슈퍼관리자 계정이 자동 생성됩니다.

- 아이디: `superadmin` / 비밀번호: `ChangeMe123!` (환경변수 `SUPERADMIN_PASSWORD`로 지정 가능)
- **첫 로그인 시 비밀번호 변경이 강제됩니다.**

## 주요 기능

### 1. 4단계 권한 체계 (계정 부여는 항상 자기보다 낮은 권한만)

| 역할 | 할 수 있는 일 |
|---|---|
| 슈퍼관리자 | 시스템 전체 관리, 관리자·강사·학생 계정 부여, 보안 정책 |
| 관리자 | 강사·학생 계정 관리, 시간표 접근 설정, 접속 기록 열람 |
| 강사 | 웹앱(PPT) 제작·발표, 학생 계정 부여 |
| 학생 | 허용된 시간에만 접속, 공개된 자료 열람 |

계정 생성 시 초기 비밀번호를 지정하며, 대상자는 첫 로그인에서 반드시 변경해야 합니다.

### 2. 요일·시간 기반 접근 제어

- 관리자 이상이 **요일 + 시작/종료 시간** 창을 등록 (기본값: 월~금 09:00~18:00)
- 특정 웹앱만 허용하는 시간창도 가능 (예: 화 19:00~20:00 "AI 진로탐색"만)
- 학생은 허용 시간 밖에는 **서버 단에서 모든 API가 차단**되고, 허용 시간표가 안내되는 대기 화면을 보게 됩니다. 차단 시도는 접속 기록에 남습니다.

### 3. PPT 웹앱 (슬라이드 덱)

- 강사 이상이 덱 생성 → 슬라이드 편집(제목·본문·테마 6종·정렬, 실시간 미리보기)
- 본문 문법: `## 소제목`, `- 글머리`, `**굵게**`, `*기울임*`, `![설명](https://이미지주소)`
- 전체화면 발표 모드: 방향키/스페이스/클릭 이동, 진행바, ESC 종료
- "공개" 상태의 덱만 학생에게 노출

### 4. 복제·캡처 억제 (보안 설정에서 개별 on/off)

- **화면 캡처 방지**: PrintScreen 감지 시 화면 가림 + 클립보드 덮어쓰기 + 기록, 개발자도구 단축키 차단, 발표 중 창 이탈 시 블랙아웃, 인쇄 차단
- **복제/복사 차단**: 우클릭·텍스트 선택·복사/잘라내기·드래그 차단
- **워터마크**: 열람자 이름·아이디·시각을 슬라이드 전체에 반복 표시
- **동시접속 제한**: 학생 계정은 마지막 로그인 기기 1대만 유지
- 모든 시도는 감사 로그(`접속 기록`)에 남습니다.

> **한계 안내(중요)**: 웹 기술로는 캡처를 100% 차단할 수 없습니다(스마트폰 촬영, OS/브라우저 수준 캡처 등).
> 이 기능들의 목적은 *차단 + 워터마크를 통한 억제 + 시도 기록을 통한 추적*입니다.

## 프로젝트 구조

```
server.js          # HTTP 서버 (정적 파일 + API 라우팅)
lib/db.js          # SQLite 스키마·시드·감사로그
lib/auth.js        # 세션·역할 서열
lib/password.js    # scrypt 비밀번호 해시
lib/schedule.js    # 요일·시간 접근 판정 (타임존 인식)
lib/api.js         # REST API (인증/사용자/시간표/덱/보안설정/로그)
public/            # SPA (index.html, app.js, style.css)
```

## 운영 참고

- 실서비스 배포 시 HTTPS(리버스 프록시) 사용을 권장합니다. HTTPS 환경이라면 `lib/api.js`의 세션 쿠키에 `Secure` 속성을 추가하세요.
- `data/` 디렉터리만 백업하면 전체 데이터가 보존됩니다.
