# AI 온라인 플랫폼 관리자 — 진로교육 PPT 웹앱

PPT 수업자료를 **인터랙티브 웹앱**으로 만들어 관리·발표하고, **요일·시간 기반으로 학생 접근을 통제**하며, **복제·캡처를 억제**하는 SaaS형 진로교육 관리 플랫폼입니다.

데이터는 **Supabase(Postgres)** 에 저장되며, 앱은 Vercel(서버리스)·Render·VPS 어디에나 배포할 수 있습니다.
배포 절차는 [DEPLOY.md](DEPLOY.md) 참고 — Vercel + Supabase 조합이면 무료로 운영됩니다.

## 실행 방법

```bash
# Node.js 22.13 이상 필요
npm install
DATABASE_URL='postgresql://...' npm start   # Supabase 연결 문자열 (DEPLOY.md 0단계 참고)
```

브라우저에서 `http://localhost:3000` 접속. 첫 실행 시 스키마·초기 계정이 자동 생성됩니다.

- 포트 변경: `PORT=8080`
- 기준 시간대: `Asia/Seoul` — `APP_TIMEZONE` 환경변수로 변경 가능
- 리버스 프록시 뒤 운영 시 `TRUST_PROXY=1`, HTTPS 환경이면 `COOKIE_SECURE=1` (Vercel은 둘 다 자동)

### 최초 로그인

첫 실행 시 슈퍼관리자 계정이 자동 생성됩니다.

- 아이디: `superadmin` / 비밀번호: `ChangeMe123!` (환경변수 `SUPERADMIN_PASSWORD`로 지정 가능)
- **첫 로그인 시 비밀번호 변경이 강제됩니다.**

## 주요 기능

### 1. 4단계 권한 체계 (계정 부여는 항상 자기보다 낮은 권한만)

| 역할 | 할 수 있는 일 |
|---|---|
| 슈퍼관리자 | 전체 시스템 관리, 관리자 권한 부여, 보안 정책 설정 |
| 관리자 | 기관 관리, 강사 관리, 웹앱 배정 관리, 접속 기록·리포트 |
| 강사 | 수업 운영(웹앱 제작·발표), 학생 관리 |
| 학생 | 허용된 시간에만 배정된 수업 웹앱 이용 |

### 2. 요일·시간 기반 접근 제어

- 관리자가 **요일 + 시작/종료 시간** 창을 등록 (기본값: 월~금 09:00~18:00)
- 특정 웹앱만 허용하는 시간창도 가능 (예: 화 19:00~20:00 "AI 진로탐색"만)
- 학생은 허용 시간 밖에는 **서버 단에서 모든 API가 차단**되고, 허용 시간표 안내 화면이 표시됩니다. 차단 시도는 접속 기록에 남습니다.
- 대시보드의 주간 매트릭스에서 접근 허용(초록)/웹앱별 허용(파랑)/차단(빨강)/자동 잠금(회색 패턴)을 한눈에 확인

### 3. 수업 입장 코드 (1회성 학생용)

- 강사가 수업명·대상 웹앱·유효 시간을 정해 **6자리 입장 코드**를 발급
- 학생은 로그인 화면의 "수업 참여"에서 **코드 + 이름만 입력**하면 즉시 입장 (계정·비밀번호 불필요)
- 수업 종료 시각이 지나거나 강사가 종료하면 **접근이 자동 차단**, 임시 계정은 하루 뒤 자동 정리 (접속·캡처 기록은 보존)
- 게스트 학생은 그 수업에 지정된 웹앱만 열람 가능, 워터마크에는 입력한 이름이 표시됨
- **라이브 발표**: 강사가 "라이브 발표"로 슬라이드를 넘기면 접속한 학생들의 화면이 **자동으로 함께 넘어감** (시작 시 자동 진입, 종료 시 자동 복귀 — 지연 1~3초)
- **수업에 여러 자료 담기 + 자료별 제어**: 한 수업(차시)에 PPT·동영상·웹앱 여러 개를 담고, 자료마다 **학생 공개 여부**와 **잠금/해제**를 개별 조절 — PPT·동영상은 학생에게 숨겨 강사 발표 전용으로, 웹앱은 잠가두었다가 활동 시간에 열어 미리 체험 방지 (해제 시 학생 화면 자동 갱신)
- **담당 강사 배정**: 관리자가 수업을 등록하면서 담당 강사를 지정하면, 그 강사가 자기 수업 목록에서 자료 관리·라이브 발표를 진행 (관리자→수업 등록→강사 배정→자료 체크 흐름)

### 4. 웹앱 배정 관리 (강사별·학생별·반별·과목별)

- 웹앱마다 **과목(폴더)** 을 지정해 분류 — 관리 화면은 과목 탭, 학생 화면은 과목별 묶음으로 표시

- 학생 계정에 **소속 반**(예: 중1-1반)을 지정
- 웹앱마다 **대상 반 + 권한 기간(시작일~종료일)** 을 배정
- 상태 자동 판정: 공개 중 / 예약(기간 전) / 만료(기간 후) / 비공개
- 학생에게는 자기 반에 배정되고 기간 내인 웹앱만 노출

### 5. PPT 웹앱 (슬라이드 덱) + 외부 체험형 웹앱

- 슬라이드 편집기: 제목·본문·테마 6종(레이어드 그라데이션·포인트 컬러)·정렬, 실시간 미리보기
- **PPT 변환**: PowerPoint에서 "내보내기 → PNG/JPEG"로 저장한 슬라이드 이미지를 일괄 업로드하면 디자인 원본 그대로 웹앱 슬라이드가 됨 (파일명 순서 자동 정렬, 이미지는 DB에 저장되어 로그인한 사용자에게만 제공)
- **내 배경 업로드**: 배경 이미지를 올리면 테마처럼 선택 가능 (글자색 밝게/어둡게 선택, 배경 라이브러리 공유)
- **내보내기(관리자 이상)**: 슬라이드를 PDF로 저장(슬라이드 1장=1페이지)하거나 JSON으로 백업 — 학생·강사의 인쇄 차단은 유지됨
- 본문 문법: `## 소제목`, `- 글머리`, `**굵게**`, `*기울임*`, `![설명](https://이미지주소)`, `!video(유튜브 또는 mp4 주소)`
- **슬라이드에 동영상·이미지 파일 직접 업로드**: 편집기에서 mp4/webm 동영상(약 25MB 이하)이나 이미지 파일을 올리면 본문 커서 위치에 삽입 — DB 저장 + HTTP Range 지원으로 탐색(seek) 가능. 긴 영상은 유튜브(일부공개) 링크 권장
- 전체화면 발표 모드: 방향키/스페이스/클릭 이동, 진행바, ESC 종료
- **HTML 파일 업로드 웹앱**: AI로 만든 단일 HTML 파일(CSS·JS 포함)을 배포 없이 그대로 업로드하면 플랫폼이 직접 서빙·실행 — 로그인·배정·시간표·워터마크가 그대로 적용되고, DB에 저장되어 URL이 유출돼도 로그인 없이는 열리지 않음
- **외부 체험형 웹앱 등록**: 별도 배포된 웹앱(예: Vercel의 체험 앱) 주소를 등록하면 학생은 플랫폼 안에서만(워터마크·시간 통제 하에) 이용
- **유출 방지 게이트**: 제공되는 한 줄 스크립트를 그 웹앱에 넣으면, 플랫폼이 발급한 **15분 유효 서명 토큰** 없이는 웹앱이 스스로 접속을 거부 — 주소가 유출되어도 직접 접속 불가

### 6. 보안 설정 (토글 8종)

| 항목 | 동작 |
|---|---|
| 화면 캡처 방지 강화 | PrintScreen 감지 시 화면 가림·클립보드 차단·로그 기록, 발표 중 창 이탈 시 블랙아웃, 인쇄 차단 |
| 복제/복사 차단 | 텍스트 선택·복사·잘라내기·드래그 차단 |
| 우클릭 차단 | 우클릭 메뉴(이미지 저장 등) 차단 |
| 워터마크 추적 | 열람자 이름·아이디·시각을 슬라이드 전면에 표시 |
| 개발자도구 감지 | 개발자도구 사용 정황 감지 시 경고 + 로그 기록 |
| 동시접속 제한 | 학생 계정은 마지막 로그인 기기 1대만 유지 (교체 시도는 로그 기록) |
| IP 제한 | 허용 IP 접두어 목록에서만 학생 로그인 허용 (관리자는 잠금 사고 방지를 위해 예외) |
| 2단계 인증 | 관리자 이상 로그인 시 인증 앱(TOTP, Google OTP 호환) 코드 요구 — 최초 로그인에서 자동 등록 |

> **한계 안내(중요)**: 웹 기술로는 캡처를 100% 차단할 수 없습니다(스마트폰 촬영, OS 수준 캡처 등).
> 본 플랫폼의 보호 전략은 *캡처 방지 강화 + 워터마크 추적 + 접속 로그 기록*의 3중 체계입니다.

### 7. 접속 기록 · 리포트 · 검색 · 알림

- 접속 기록: 모든 접속/차단/보안 이벤트 + IP·브라우저 정보, 필터(정상/차단/보안 경고)
- 리포트: 최근 7일 활동 추이 차트, 웹앱 열람 순위, 주간 활동 학생 TOP 5
- 상단 검색창: 웹앱·사용자·로그 통합 검색
- 알림: 최근 24시간 보안 경고(캡처 시도·다중 접속·IP 차단 등) 요약

## 프로젝트 구조

```
server.js          # 상시 실행 서버 (로컬/VPS/Render용 — 정적 파일 + API)
api/index.js       # Vercel 서버리스 함수 진입점
vercel.json        # Vercel 라우팅·리전 설정
lib/db.js          # Postgres(Supabase) 연결·스키마·시드·감사로그
lib/auth.js        # 세션·역할 서열
lib/password.js    # scrypt 비밀번호 해시
lib/totp.js        # RFC 6238 TOTP (2단계 인증)
lib/schedule.js    # 요일·시간 접근 판정 (타임존 인식)
lib/api.js         # REST API (인증/사용자/시간표/덱/배정/보안/리포트/로그)
public/            # SPA (index.html, app.js, style.css)
```
