# 광장 5단계 로컬 시험 절차

실제 학생에게 사용할 절차가 아니다. 0단계 `plaza-plan.md`, `plaza-design.md`와 4단계 개인정보 관문을 유지한다. 가짜 참여자와 새 로컬 시험 DB·저장소만 쓴다.

## 환경

1~4단계 시험 환경에 `PLAZA_STAGE5_TEST=1`을 추가한다. `PLAZA_STAGE4_TEST=1` 및 그 선행 단계가 필요하다. `DATABASE_URL`은 루프백의 새 `plaza_test_...` DB여야 하며, 사진 저장소는 저장소 밖의 새 절대 경로다. `VERCEL` 환경에서는 실행되지 않는다. `PLAZA_SYNTHETIC_KIT=1`을 명시했을 때만 가짜 재료 카드가 제공된다.

빈 시험 DB에서 `PLAZA_SETUP_CONFIRM=disposable-local-test`로 `node scripts/plaza-stage5-setup.js`를 실행한다. 이 스크립트는 4단계까지의 수동 시험 스키마 준비를 이어 쓴다. `lib/db.js` 자동 적용 목록은 바꾸지 않는다. 접속 정보가 든 `fixture.json`은 비공개 시험 저장소에만 생기며 공개하거나 커밋하지 않는다.

일반 로컬 Node 서버는 `npm start`로 실행한다. 서버와 시험 스크립트가 같은 로컬 DB·포트를 볼 수 있어야 한다. 프로세스별 네트워크가 격리되는 환경에서는 DB 소켓·서버·검증을 같은 Node 프로세스에서 실행한다.

## 강사 준비

1. 기존 수업 자료 화면에서 실제 자료를 만들고, 기존 수업 코드 화면에서 그 자료를 배정한다. 학생 공개와 잠금 해제 상태를 확인한다.
2. 광장 수업 진행 → 프로그램 카드와 수업 준비를 연다.
3. 조향사 또는 공예디자이너 기본 카드를 불러온다. 실제 키트가 확인되지 않은 카드는 재료·조합이 비어 있는 `키트 목록 확인 대기` 상태다. 자동 시험에는 별도로 표시된 가짜 재료 카드를 쓴다.
4. 자료와 카드 버전을 확인하고 등록한다. 같은 프로그램 키·버전의 다른 내용은 거부된다. 수정할 때는 버전을 올려 새로 등록한다. 확장 담당자가 추가 선택지를 편집할 때만 상세 JSON 편집을 연다. 교안·개인정보·HTML·주소는 넣지 않는다.
5. 담당 수업, 등록된 버전, 실제 자리 수를 선택해 광장을 준비한다. 기존 광장에는 새 버전을 덮어씌우지 않으며 종료된 광장은 재사용하지 않는다.
6. 관리자가 기존 광장 보관·파기 화면에서 시험 보관 기간을 등록한다. 등록 전에는 학생이 입장할 수 없다. 강사 교안은 해당 광장 강사 화면에서 별도로 등록한다.

## 학생 카드 확인

가짜 참여자가 기존 수업 코드와 명시적 기록·사진 선택으로 들어와 구상, 제작 확인, 교류, 돌아보기를 완료한다. 마지막에 확인한 진로기록을 실제 저장한 뒤 **내 QR 진로 카드 확인·인쇄**를 누른다. 최종 저장 전이나 진로기록 없이 참여한 경우에는 이 버튼을 제공하지 않는다. 내 진로기록 목록의 저장된 광장 기록에서도 카드를 연다.

카드의 과정·결과물·돌아보기를 읽고 인쇄 버튼을 누른다. 버튼은 서버 권한을 다시 조회한 후 인쇄를 연다. QR에는 기록 주소만 들어 있으며 접속 권한을 주지 않는다. 현재 주소는 시험 서버 컴퓨터의 `127.0.0.1:<PORT>`를 가리킨다. 다른 기기에서 사용할 운영 QR로 나눠 주지 않는다.

수업 코드 접속은 종료·만료·재발급으로 폐기된다. 인쇄물을 나중에 다시 보는 것과 온라인 기록을 계속 열 수 있는 것은 별개다. 학교 장기 계정으로 자동 연결하지 않는다. 이미 정정된 기록의 예전 QR이 열리지 않으면 기존 내 진로기록 목록에서 현재 기록을 확인한다.

## 자동 시험

`npm run check`, `npm test`를 실행한다. 새 시험 환경의 `fixture`와 로컬 서버 주소로 `require('./scripts/plaza-stage5-verify').verify({fixture,base})`를 호출하면 API 등록·권한·공예/조향사 완주·QR 조회·기기 연결·기록 불변을 시험한다. 이 검증은 시험 DB 표식을 확인하며 중앙 학교 계정을 만들거나 변경하지 않는다.

공통 합성 참여자 스크립트 `scripts/plaza-rehearsal.js`는 카드의 선택지를 읽어 사용한다. 프로그램마다 새 인증·방문·사진 코드를 만드는 방식이 아니다. 이전 4단계 보관·파기 시험도 함께 확인한다.

실물 QR 스캔, 브라우저 인쇄 미리보기·실제 출력, 다른 기기에서의 로그인 복귀는 별도 시험으로 남아 있다. 이 시험 구현만으로 실제 시범 수업이나 개인정보·운영 배포 관문을 통과한 것으로 표시하지 않는다.
