# 계약조건 검토 및 개정 초안 — 관리자 미팅용

> 목적: 관리자(Admin)가 서명하는 **플랫폼 이용·계약 동의서**를 점검하고, 미팅에서 **더 정해야 할 조건**을 결정한 뒤 그 자리에서 서명할 수 있도록 준비한 문서입니다.
> 본 문서의 계약은 앱 안의 전자 동의서 기능(성명·시각·IP 기록, 전자 동의 = 서명 효력)으로 반영됩니다.
> ⚠️ 본 초안은 법률 자문을 대체하지 않습니다. 금액·기간·책임한도 등 핵심 조건 확정 후, 필요 시 전문가 검토를 권장합니다.

---

## A. 현행 동의서 진단 (한눈에)

현재 서명 대상 문서는 **「AI 온라인 플랫폼 이용 및 비밀유지 동의서」**(7개 조항)이며, 내용은 *보안·기밀 보호*에 집중되어 있습니다.

| 조 | 제목 | 요지 |
|---|---|---|
| 제1조 | 목적 | 회사–이용자(관리자·강사) 간 콘텐츠 이용·개인정보/기밀 보호 |
| 제2조 | 비밀유지 | 학생 개인정보·수업자료·접속기록·운영정보 누설 금지 |
| 제3조 | 콘텐츠 보호 | PPT·동영상·웹앱 무단 복제·배포·캡처 금지 |
| 제4조 | 개인정보 | 수업 목적 외 처리 금지, 종료 후 파기 |
| 제5조 | 계정 보안 | 계정 공유 금지, 유출 시 통지 |
| 제6조 | 책임 | 위반 시 법령·계약에 따른 책임 |
| 제7조 | 동의 | 전자 동의 = 서명 효력 |

### 빠져 있는 영역 (= 내일 "더 정할 부분")

현행 동의서는 **거래·사업 관계**를 전혀 다루지 않습니다. 이 플랫폼은 실제로:
- OpenAI 등 **외부 API 실비를 사용량 비율로 강사·수업·자료에 배분·정산**하고,
- **관리자를 슈퍼관리자가 임명**해 강사·학생·웹앱·리포트를 위임 관리합니다.

그런데 서명 문서에는 아래 4개 영역이 **한 줄도 없습니다.** 이번 미팅의 핵심 안건입니다.

1. **비용·정산 분담** — 누가 API 실비를 부담하고 어떻게 정산하나
2. **관리자 권한·역할 범위** — 관리자가 무엇을 할 수 있고, 무엇에 책임지나
3. **계약 기간·해지** — 언제까지, 어떻게 끝내나
4. **손해배상·준거법·분쟁** — 문제가 생기면 어떻게 처리하나

## B. 추가·보완 조항 초안 (조문 형태)

아래는 현행 제7조 뒤에 **신설로 이어붙일 조항 초안**입니다. `〔TBD: …〕`는 미팅에서 채울 빈칸입니다.

### 제8조 (비용 부담 및 정산)
① "API 유료" 자료 이용에 따라 외부 제공자(OpenAI 등)에 발생하는 실비는 〔TBD: 부담 주체 — 회사 전액 / 관리자 부담 / 회사·관리자 분담〕가 부담한다.
② 이용료는 **제공자의 실제 청구액을 기준**으로 하며, 각 관리자·강사·수업·자료에 대한 배분액은 **측정된 API 호출 비율**(배분액 = 실청구액 × 대상 호출수 ÷ 해당 제공자 전체 호출수)로 산정한다. 배분 총액은 청구서 총액과 일치한다.
③ 이용자는 플랫폼이 기록하는 **사용량 집계(호출수·이용 학생 수 등)를 정산의 근거 자료로 인정**한다.
④ 정산 주기는 〔TBD: 월별 / 분기별〕로 하며, 회사는 매 〔TBD: 예) 익월 5일〕까지 배분 내역을 통지하고, 이용자는 통지일로부터 〔TBD: 예) 14일〕 이내에 납부한다.
⑤ 기한 내 미납 시 회사는 〔TBD: 지연이자 / 이용 일시정지〕를 적용할 수 있다.

### 제9조 (관리자의 권한과 역할 범위)
① 관리자는 자신에게 부여된 범위에서 **강사·학생 관리, 웹앱 배정, 접속 기록·리포트 열람, 수업·시간표 운영**을 수행한다.
② **관리자 계정의 생성·임명·권한 변경은 슈퍼관리자 전용 권한**이며, 관리자는 자신보다 낮은 권한(강사·학생) 계정만 발급할 수 있다.
③ 관리자는 부여된 권한을 제3자에게 재위임하거나 양도하지 않는다.
④ 관리자는 자신이 관리하는 강사·학생의 플랫폼 이용이 본 동의서를 준수하도록 **감독할 의무**를 지며, 관리 범위 내에서 발생한 위반에 대해 〔TBD: 감독 책임 범위 — 고의·중과실 한정 / 관리 범위 전체〕의 책임을 진다.

### 제10조 (계약 기간 및 해지)
① 본 계약의 기간은 서명일로부터 〔TBD: 예) 1년〕으로 하며, 만료 〔TBD: 예) 30일〕 전까지 별도 의사표시가 없으면 동일 조건으로 자동 갱신된다. 〔대안: 무기한, 통지에 의한 해지〕
② 각 당사자는 〔TBD: 예) 30일〕 전 서면(전자 포함) 통지로 계약을 해지할 수 있다.
③ 상대방이 본 동의서를 중대하게 위반하거나 정산금을 기한 내 납부하지 않는 경우, 회사는 최고 후 계약을 즉시 해지하고 이용을 정지할 수 있다.
④ 계약 종료 시 이용자 계정과 관련 데이터는 〔TBD: 예) 30일〕 내 처리·파기하며, **미정산분은 종료일 기준으로 정산·청산**한다.

### 제11조 (손해배상·준거법·분쟁)
① 이용자가 본 동의서를 위반하여 회사 또는 제3자에게 손해를 입힌 경우, 이용자는 그 손해를 배상한다. 배상 한도는 〔TBD: 무한 / 최근 N개월 이용료 상당 / 고의·중과실 제외〕로 한다.
② 학생 개인정보 유출 등 사고 발생 시, 이용자는 지체 없이 회사에 통지하고 회사의 대응 조치에 협조한다.
③ 본 계약은 **대한민국 법**에 따르며, 분쟁은 〔TBD: 회사 본점 소재지 관할 법원 / 협의 후 지정〕을 1심 관할로 한다.

## C. 미팅 결정 항목표 — "더 정할 부분"

미팅에서 아래 빈칸을 채우면 그대로 계약이 확정됩니다. **권고안**은 일반적 SaaS 관행 기준 제안일 뿐, 최종은 협의로 정합니다.

| # | 결정 항목 | 선택지 | 권고안 |
|---|---|---|---|
| 1 | API 실비 부담 주체 (제8조①) | A. 회사 전액 / B. 관리자 부담 / C. 분담(비율 지정) | 초기엔 A, 규모 커지면 C 전환 |
| 2 | 정산 주기 (제8조④) | A. 월별 / B. 분기별 | A(월별) — 사용량 변동 반영 쉬움 |
| 3 | 통지·납부 기한 (제8조④) | 예: 익월 5일 통지 / 14일 내 납부 | 익월 5일 / 14일 |
| 4 | 미납 시 처리 (제8조⑤) | A. 지연이자 / B. 이용정지 / A+B | A+B(최고 후) |
| 5 | 관리자 감독 책임 범위 (제9조④) | A. 고의·중과실 한정 / B. 관리범위 전체 | A(고의·중과실) |
| 6 | 계약 기간·갱신 (제10조①) | A. 1년 자동갱신 / B. 무기한+통지해지 | A(1년 자동갱신) |
| 7 | 해지 통지 기간 (제10조②) | 예: 30일 / 60일 | 30일 |
| 8 | 종료 시 데이터 처리기한 (제10조④) | 예: 30일 / 즉시 | 30일 |
| 9 | 손해배상 한도 (제11조①) | A. 무한 / B. N개월 이용료 상당 / C. 고의·중과실만 | B 또는 C(과도한 위험 제한) |
| 10 | 분쟁 관할 (제11조③) | A. 본점 소재지 법원 / B. 협의 지정 | A(본점 소재지) |

> 표의 각 행을 채운 뒤, 그 값을 B의 `〔TBD〕` 자리에 반영하면 최종 문안이 완성됩니다.

## 부록 — 확정 후 앱 반영 절차 (슈퍼관리자용)

미팅에서 문안이 확정되면 아래 순서로 반영합니다. **기능 개발 없이 문구 교체만으로** 전원 재동의가 걸립니다.

1. 슈퍼관리자로 로그인 → **"계약 관리"** 화면 진입.
2. 확정된 전체 문안(현행 제1~7조 + 신설 제8~11조)을 **본문에 붙여넣기**.
3. **"개정(버전 올림)"** 실행 → 시스템이 관리자·강사 **전원에게 재동의**를 요구합니다.
   - 이후 각 관리자·강사는 다음 접속 시 동의 화면이 뜨며, 동의 전에는 기능 이용이 차단됩니다(성명·시각·IP 기록).
4. **"미동의 대상 / 동의 기록"** 목록에서 누가 서명했는지 확인합니다.

> 참고: 신규 설치 시 자동으로 들어가는 기본 문안(코드의 `DEFAULT_AGREEMENT`)에도 신설 조항 골격이 반영되어 있으나, **금액·기간 등 `〔TBD〕` 값은 각 조직이 계약 관리에서 채워 넣어야** 합니다.
